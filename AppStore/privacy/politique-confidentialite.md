# Politique de confidentialité de Check Pap

Dernière mise à jour : [À COMPLÉTER : date de publication]

Check Pap est un service indépendant qui aide à préparer des démarches administratives. Cette page explique quelles informations l'app utilise et où elles restent.

## En résumé

- **Aucune donnée n'est collectée.** Rien de ce que vous saisissez n'est envoyé à Check Pap ni à qui que ce soit.
- **Pas de compte, pas de publicité, pas de suivi**, pas d'outil de mesure d'audience.
- **Tout reste sur votre téléphone**, et disparaît si vous supprimez l'app.

## Ce que l'app enregistre sur votre téléphone

Uniquement pour vous rendre service, et uniquement sur votre appareil :

- la langue choisie et votre code postal (pour trouver votre préfecture) ;
- vos réponses aux questionnaires, les pièces cochées ou retirées, les étapes faites ;
- la date de fin de votre titre de séjour, si vous l'indiquez ;
- vos rendez-vous enregistrés (date, lieu, notes) ;
- les informations que vous tapez pour préparer un courrier (nom, adresse, numéro étranger...), pour ne pas avoir à les retaper.

Ces informations peuvent faire partie de la sauvegarde de votre iPhone (iCloud ou ordinateur), selon vos propres réglages. Check Pap n'y a pas accès.

## Ce que l'app ne fait que sur votre demande

- **Calendrier** : le bouton "Ajouter au calendrier" ouvre l'écran de l'iPhone ; c'est vous qui validez. L'app ne lit pas votre calendrier.
- **Notifications** : les rappels sont programmés sur votre téléphone (sans serveur), seulement si vous les activez.
- **Courriers** : quand vous copiez, partagez ou envoyez un courrier, il part avec l'application que vous choisissez (Mail, Messages...).
- **Liens** : les liens vers les sites de l'administration s'ouvrent dans votre navigateur ; ces sites ont leur propre politique de confidentialité.

## Effacer vos données

Supprimez un dossier dans l'onglet "Mes dossiers", ou supprimez l'app : toutes les informations enregistrées sont effacées.
